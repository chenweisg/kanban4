Portfolio summary

    Demo mode: tasks live in memory only. Refreshing the page resets the board to the sample data.

    How this page protects your data
    • Nothing is stored: no cookies, local storage or databases. Closing the tab clears everything.
    • The page can only connect to FormSubmit, and only when you add a task. All other outside connections are blocked.
    • Text you type is cleaned and shown as plain text, so it can never run as code.
    • Email notifications are limited to one every 10 seconds, and are skipped until a real address is configured.
